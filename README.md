## 🚀 Déploiement sur GitHub Pages

### Méthode 1 : Upload direct (recommandée pour débuter)

**Étape 1 — Créer le dépôt GitHub**
1. Allez sur [github.com](https://github.com) et connectez-vous
2. Cliquez **"New repository"** (bouton vert en haut à droite)
3. Nom du dépôt : `idelphonse-web3` (ou votre choix)
4. Visibilité : **Public** (obligatoire pour GitHub Pages gratuit)
5. Cliquez **"Create repository"**

**Étape 2 — Uploader tous les fichiers**
1. Dans le dépôt créé, cliquez **"uploading an existing file"**
2. Glissez-déposez **TOUS** les fichiers suivants :
   ```
   index.html, debutant.html, intermediaire.html, avance.html,
   ambassadeur.html, glossaire.html, coaching.html, contact.html,
   dashboard.html, certification.html, verification.html,
   style.css, script.js, progress.js, signature.js,
   signature-idelphonse.png, signature-idelphonse.svg
   ```
3. Message de commit : `🚀 Initial deploy - Idelphonse Web3 Platform`
4. Cliquez **"Commit changes"**

**Étape 3 — Activer GitHub Pages**
1. Onglet **Settings** de votre dépôt
2. Menu gauche : **Pages**
3. Source : **Deploy from a branch**
4. Branch : **main** · Folder : **/ (root)**
5. Cliquez **Save**
6. ⏳ Attendre 2-3 minutes

**Votre site sera en ligne sur :**
```
https://VOTRE-USERNAME.github.io/idelphonse-web3/
```

